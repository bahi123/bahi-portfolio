# Bahi Portfolio

A static bilingual personal portfolio.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a public GitHub repository (e.g. `bahi-portfolio`).
2. Upload ALL contents of this folder at the repository root.
3. In Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`.
4. Wait for the Pages deployment to complete, then use the URL shown by GitHub.

## Publish with Vercel
1. Import the repository to Vercel or upload this folder using Vercel's supported deployment flow.
2. Choose framework preset `Other`, no build command, output root `.`.
3. Deploy; Vercel will assign the live URL.

## Before publishing
- Review the AI-enhanced portrait and replace it with an approved personal photo if preferred.
- Review PDF CV and contact information for public visibility.
- Replace placeholders in the evidence gallery with screenshots ONLY AFTER redacting IP addresses, device names, credentials, topology specifics, customer data, and log metadata.
- Obtain employer/customer permission before sharing internal system screenshots.

The site uses no backend and does not collect visitor data. Google Fonts are loaded from Google.
